Конфигурации стилей различных компонентов вынесены в отдельный файл, вне предела className из-за чего tailwind не считает их классами и не подсказывает. Чтобы это исправить добавляем в user settings json (ctrl+p > open user settings)

```json
"tailwindCSS.experimental.classRegex": [
	["clsx\\(([^)]*)\\)", "[\"'`]([^\"'`]*).*?[\"'`]"],
	["cva\\(([^)]*)\\)", "[\"'`]([^\"'`]*).*?[\"'`]"]
]
```
после этого любой текст обернутый в clsx будто считаться tailwind классом и будут появляться подсказки
