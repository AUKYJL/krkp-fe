# TaxiFleet Pro Frontend

Клиентская часть приложения для управления таксопарком. Frontend предоставляет интерфейс для директора и водителя, отображает данные о таксопарках, автомобилях, водителях, сменах и аналитических показателях.

## Основной функционал

Для директора:

- просмотр dashboard с общей аналитикой;
- управление таксопарками;
- управление автомобилями;
- управление водителями;
- просмотр рейтингов, графиков и KPI;
- анализ выручки, простоев и эффективности работы таксопарка.

Для водителя:

- просмотр личного dashboard;
- просмотр закрепленного автомобиля;
- выход на смену;
- ввод и редактирование выручки за активную смену;
- просмотр финансов и истории рабочих дней.

## Требования

Перед запуском необходимо установить:

- Node.js;
- npm;
- запущенный backend-сервер.

## Установка

Перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

## Настройка переменных окружения

Создайте файл `.env` в папке frontend и укажите адрес backend-сервера:

```env
VITE_API_URL="http://localhost:5001"
```

## Запуск проекта

Соберите проект:

```bash
npm run build
```

Запустите frontend:

```bash
npm run preview
```

После запуска приложение будет доступно в браузере по адресу:

```text
http://localhost:5173
```

## Проверка работы

После запуска необходимо открыть приложение в браузере и проверить:

1. отображение страницы авторизации;
2. регистрацию или вход пользователя;
3. загрузку dashboard;
4. отображение данных о таксопарках, автомобилях и водителях;
5. корректное отображение графиков и аналитических показателей.

## Основные разделы интерфейса

```text
Главная — dashboard пользователя
Таксопарки — просмотр и управление таксопарками
Водители — управление водителями, доступно директору
Автомобили — просмотр и управление автомобилями
Финансы — просмотр выручки и динамики по рабочим дням
```

## Порядок запуска всей системы

1. Запустить PostgreSQL.
2. Запустить backend на `http://localhost:5001`.
3. Запустить frontend.
4. Открыть `http://localhost:5173`.
5. Авторизоваться и приступить к работе.
