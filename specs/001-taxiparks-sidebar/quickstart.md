# Quickstart: Taxi Parks Sidebar

**Created**: 2026-05-29  
**Plan**: `specs/001-taxiparks-sidebar/plan.md`

## Prerequisites

- Node.js installed
- Dependencies installed (already present in this repo via `node_modules/` or install via your package manager)

## Run locally

- Dev server: `yarn dev` (or `npm run dev`)
- Lint: `yarn lint` (or `npm run lint`)
- Build: `yarn build` (or `npm run build`)

## Design reference

- Pencil Node ID: `jRRvC` (sidebar + tokens)
